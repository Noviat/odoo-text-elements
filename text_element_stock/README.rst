=====================
Text Elements - Stock
=====================

Text elements on delivery slips.

Print the texts of the catalogue on delivery slips: handling instructions, return
conditions, a message to the consignee. Use a condition on the operation type to
keep a text for deliveries or for receipts.

This module adds the **Text Elements** tab to the form and prints the texts at the
position chosen in the catalogue: top of document, before lines, after totals or
bottom of document, in the customer's language.

.. image:: https://raw.githubusercontent.com/Noviat/odoo-text-elements/19.0/text_element_stock/static/description/delivery_slip_report.png
   :alt: A delivery slip with handling instructions before the moves

Requirements
============

**Text Elements** (``text_element_base``), which holds the catalogue, the
conditions, the dynamic placeholders and the preview. See its README for the
configuration.

Usage
=====

Open the **Text Elements** tab of a document to see the texts that will be
printed, add texts from the catalogue, personalise one, or write a free text.
