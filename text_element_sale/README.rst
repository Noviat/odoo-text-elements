====================
Text Elements - Sale
====================

Text elements on quotations and sales orders.

Print the texts of the catalogue on quotations and sales orders: an introduction
letter addressed to the customer, a deposit clause above an amount, delivery
terms, a seasonal notice.

This module adds the **Text Elements** tab to the form and prints the texts at the
position chosen in the catalogue: top of document, before lines, after totals or
bottom of document, in the customer's language.

.. image:: https://raw.githubusercontent.com/Noviat/odoo-text-elements/20.0/text_element_sale/static/description/sale_order_report.png
   :alt: A sales order with an introduction letter, a deposit clause and a closure notice

.. image:: https://raw.githubusercontent.com/Noviat/odoo-text-elements/20.0/text_element_sale/static/description/document_tab.png
   :alt: The Text Elements tab of a sales order

Requirements
============

**Text Elements** (``text_element_base``), which holds the catalogue, the
conditions, the dynamic placeholders and the preview. See its README for the
configuration.

Usage
=====

Open the **Text Elements** tab of a document to see the texts that will be
printed, add texts from the catalogue, personalise one, or write a free text.
