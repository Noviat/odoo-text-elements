On a quotation or an invoice, the **Text Elements** tab lists every text
printed on the document. Each line shows where it is printed and its source:

* **Catalogue** — follows the catalogue text: a correction made in the
  catalogue is printed on the next print.
* **Personalised** — a copy adapted for this document, written in the
  customer's language. The conditions of the catalogue text still apply.
  *Revert* returns to the catalogue text.
* **Free text** — written for this document only, always printed.

A warning tells when a line will not be printed because its condition is not
met or its validity period is over.

* **Add from catalogue** opens the catalogue texts that can still be added;
  select several and confirm.
* **Add free text** writes a text for this document only.
* **Personalise** copies a catalogue text to adapt it.
* **Reapply default text elements** adds the automatic texts the document
  lacks and removes the automatic ones that no longer apply. Texts added by
  hand or personalised are kept. The same happens when the customer or the
  company of the document changes.

Automatic texts created after a document are not added to it until one of
these happens, so that sent documents do not change on reprint.
